Hello, world.

Vince Gerano

IT student and aspiring web developer

Hi, I’m Vince Gerano, an Information Technology student who enjoys turning ideas into things people can click, play, and explore. I’m currently learning HTML and CSS to build responsive websites, and I use Git and GitHub to keep track of my work.

I also practice C++ and build small games in Roblox Studio with Luau. What excites me most about technology is how a few lines of code can become something interactive, from a personal portfolio to an animated map of the solar system. I’m aiming to grow into a web developer who writes clean, readable code and keeps learning with every project. I’m always open to feedback, new tools, and teammates who want to build something together.
